<objective>
Close UAT gap G-05-1 (NFR-01 gate failed: offscreen document still present after 13 idle minutes with 49 tabs open). First confirm the diagnosed root cause with a failing regression test, then fix the offscreen lifecycle so an idle browser actually reaches the D-01 idle teardown and stays torn down.

Purpose: The D-01 idle teardown never fires in practice. Root cause (diagnosed as "likely" in 05-HUMAN-UAT.md, which this plan confirms first): `handleAlarmTick` runs every minute and re-classifies every background http tab. Once tab-history passes cold start, every tick sends CLASSIFY_BATCH, and `classifyBatch`'s finally block re-arms the 10-minute timer, so the timer can never elapse. Code reading found three more contributors in real Chrome:
- (a) the teardown timer is an in-memory SW timer, which is lost whenever the SW is suspended;
- (b) `classifyBatch` calls `ensureOffscreen()` before checking whether anything needs inference, so any tick with candidates recreates a torn-down document;
- (c) `index.ts` eagerly creates the document on every SW boot.

All four must be fixed for the NFR-01 truth to hold.

Output:
- A new end-to-end regression test `src/background/offscreen-idle.test.ts`.
- A freshness-gated `classifyBatch` with chrome.alarms-scheduled teardown in `src/background/classifier.ts`.
- Two new constants and two optional cache fields.
- Alarm routing in `index.ts`, with the boot warm-up removed.
- An updated NFR-01 runbook and permission justifications.

Out of scope: UAT test 2 (cross-OS screenshots). It is blocked on Windows/macOS hardware and is not a code issue.
</objective>
